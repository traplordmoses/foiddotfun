## How to Use the Pitch Deck

### Option 1: Marp CLI (Recommended)

```bash
# Install Marp CLI
npm install -g @marp-team/marp-cli

# Generate PDF
marp ethdenver-2026.md --pdf --allow-local-files

# Generate HTML (for browser presentation)
marp ethdenver-2026.md --html --allow-local-files

# Live preview
marp ethdenver-2026.md --preview
```

### Option 2: Marp for VS Code

1. Install "Marp for VS Code" extension
2. Open `ethdenver-2026.md`
3. Click the Marp icon in the top right to preview
4. Export to PDF/PPTX/HTML from the menu

### Option 3: Slidev

```bash
# Install Slidev
npm install -g @slidev/cli

# Convert and run (may need minor syntax adjustments)
slidev ethdenver-2026.md
```

### Option 4: Google Slides / PowerPoint

1. Generate HTML with Marp
2. Copy content into Google Slides
3. Manually adjust styling
